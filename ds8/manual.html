DS-8 User Manual

This manual documents the main controls and workflows for using DS-8 on PS Vita. The UI is controlled by focus: move the focus to a section or control, then use the button shown in the footer to act on it.

Version highlights

What's New in v0.6

v0.6 expands how DS-8 connects to a music setup:

  • Record the stereo master and eight individual tracks simultaneously over USB.
  • Send stereo USB audio into DS-8 and record it directly in the sampler.
  • Keep DS-8 in time with other music gear using USB MIDI clock and transport control.

USB setup required: install the supplied PS Vita USB plugin before using these USB features. DS-8 still works normally without it, but USB audio and USB MIDI will be unavailable.

Core Ideas

DS-8 has three normal work areas: Transport, Sequencer, and Voice. Playlist mode adds a playlist arranger and XY performance area.

Most screens follow the same rules:

ControlMain use
DPADMove focus, choose rows, or make coarse changes.
Left/right stickEdit the focused value continuously.
CROSSEnter, confirm, toggle, launch, or open the focused item.
CIRCLEBack, close, cancel, or open lane operations in the sequencer.
SQUARESecondary action: presets, mute/solo popup, precision hold, page swap, or picker set.
TRIANGLELocks/automation, preview, copy, reseed, or next parameter.
L / RSwitch major areas, or switch steps/pages/ranges inside modals.
STARTPlay/stop in most places. In name-entry screens it saves the entered name.
SELECTOpen Settings from normal screens. Some sampler edit screens use it to assign the pending sample.

Footer hints at the bottom of the screen are the best guide for the current focus. If a button seems inactive, move focus and check the footer.

Starting and Moving Around

Press START to play or stop the transport. Press SELECT to open Settings. Press L / R to move between top-level areas.

When a section frame is focused, press CROSS to enter that section's controls. Use CIRCLE to back out through the current hierarchy. In many lists and grids, moving past an edge returns focus to the parent section.

Hold a D-pad direction to repeat movement. DS-8 distinguishes a single press from a held repeat, especially in the sequencer and picker popups.

Transport

Transport contains play state, BPM, pattern navigation, the pattern menu, the pattern/playlist switch, and playlist-specific controls when Playlist view is active.

Common transport actions:

FocusAction
Play/stopSTART toggles playback globally.
BPMDPAD UP/DOWN changes tempo; stick left/right gives continuous adjustment in Settings.
Pattern selectorCROSS opens the pattern menu.
Pattern menuDPAD UP/DOWN chooses a pattern, APPEND EMPTY, or APPEND CLONE; CROSS confirms; CIRCLE closes.
Pattern/playlist switchCROSS opens Playlist view, or returns to Pattern view when Playlist view is active.

Playlist END actionIn Playlist view, CROSS cycles end behavior.
Playlist ADDIn Playlist view, CROSS opens the pattern picker for adding a playlist row.

Pattern length is edited from the Voice parameter grid with the LENGTH card. Press CROSS on LENGTH to cycle the active pattern between available page counts.

Settings and Projects

Press SELECT from a normal screen to open Settings. Use DPAD UP/DOWN to choose a row and DPAD LEFT/RIGHT to change rows that have values. Press CIRCLE to close.

Settings rows:

RowUse
BPMChange tempo. Stick left/right also edits BPM.
EXTEND CLONEChoose how added pattern pages are initialized.
THEMEChange color theme.
LOAD/SAVEPress CROSS to open Projects.
CLEAR PATTERNPress CROSS to clear the current pattern.

Projects stores complete .ds8p songs. In the Projects modal:

ViewControls
ActionsDPAD UP/DOWN selects NEW, SAVE, SAVE AS, LOAD, or DELETE; CROSS opens or runs it; CIRCLE closes.
ListDPAD UP/DOWN selects a project; CROSS loads or prepares delete; CIRCLE returns to actions.
ConfirmCROSS confirms; CIRCLE cancels. Dirty-load prompts may use DPAD to choose the option before CROSS.
Name entryDPAD LEFT/RIGHT moves the cursor, DPAD UP/DOWN cycles characters, hold SQUARE for the keyboard popup, TRIANGLE deletes, START saves, CIRCLE backs out.

The name keyboard is also used by preset saving.

USB Audio and MIDI

DS-8 v0.6 can send multitrack audio and MIDI timing over USB, and receive stereo USB audio for sampling. These USB features require the separately installed psvita_usb_midi.skprx kernel plugin. Installing the DS-8 VPK alone does not install or activate the kernel plugin.

Before You Install

  • Back up ur0:tai/config.txt before changing it.
  • Disable VITAUVC00, VITASTICK, or any other plugin that takes over the Vita USB device connection.
  • Turn off VitaShell USB mode before using DS-8 USB features.
  • Incorrect taiHEN configuration or a plugin conflict can prevent normal startup. Hold L while booting to bypass plugins if you need to recover.

Install the USB Kernel Plugin

  1. Download the latest plugin package from the PS Vita USB Audio + MIDI releases page and extract it.
  2. Copy the extracted psvita_usb_midi.skprx to ur0:tai/.
  3. Open ur0:tai/config.txt and find the existing *KERNEL section.
  4. Add ur0:tai/psvita_usb_midi.skprx on its own line beneath *KERNEL. Do not create a second *KERNEL section.
  5. Save the configuration and reboot the Vita.
  6. Launch DS-8 and connect the Vita to the host with USB. The class-compliant device appears as PS Vita USB.

DS-8 already includes the app-side USB component. Only the .skprx kernel plugin needs to be installed manually.

USB Audio Channels

DirectionFormatUse
Vita to host10 channels at 48 kHz, 16-bitMaster L/R followed by Tracks 1-8 as discrete pre-FX channels for multitrack recording.
Host to VitaStereo at 48 kHz, 16-bitUSB audio input for the sampler recording, trimming, slicing, and assignment workflow.
USB MIDIClock and transportTiming Clock, Start, Continue, and Stop for external synchronization.

If the kernel plugin is missing or incompatible, DS-8 continues to run but USB audio and USB MIDI are unavailable.

Remove or Recover the Plugin

  1. Remove the ur0:tai/psvita_usb_midi.skprx line from ur0:tai/config.txt.
  2. Reboot the Vita, then delete the plugin file if you no longer need it.
  3. If a conflict prevents normal startup, hold L during boot, remove the line, and reboot again.

Sequencer

The sequencer shows tracks as rows and steps as columns. Move around with the D-pad.

ControlAction
DPADMove selected track/step. Left/right can cross page boundaries.
CROSS releaseToggle the selected step.
TRIANGLEOpen Step Automation for the selected step.
SQUAREOpen the Track Action popup.
CIRCLEOpen Lane Actions when available.

Track Action Popup

Press SQUARE on an editable track in the sequencer to manage mute and solo states. The popup opens on the current active state when possible.

ActionMeaning
MUTEToggle mute immediately.
SOLO / SOLO +Solo the selected track immediately.
UNMUTE ALLClear all mutes.
UNSOLO ALLClear all solos.
MUTE QQueue a mute toggle for the next bar boundary.
SOLO QQueue a solo toggle for the next bar boundary.

Use DPAD to pick an action, release SQUARE to set it, or press CIRCLE to cancel. START still toggles playback.

Lane Actions

Press CIRCLE on a valid sequencer lane to open lane operations.

ActionMeaning
COPY TRK / PASTE TRKCopy or paste the track sound/settings.
COPY STEPSCopy a selected range of steps on the current page.
COPY ALLCopy the full active pattern lane.
PASTEPaste copied lane data from the selected step.
PASTE TO ENDPaste the copied range repeatedly to the end.
CLEAR TRKClear the track sound/settings.
CLEAR SEQClear sequencer hits for the lane.
CLEAR AUTOClear automation for the lane.

Use DPAD to choose an action. For copy range actions, use L / R to adjust the copied range. Release CIRCLE to apply the focused action, or press SQUARE to cancel.

Step Automation

Press TRIANGLE on a sequencer step to open Step Automation. The modal edits the selected step while keeping playback available.

Main controls:

ControlAction
CIRCLEClose the modal.
STARTPlay/stop.
L / RMove to previous/next step while keeping the modal open.
DPADMove through pages and parameter cards.
Stick left/rightEdit the focused value.
Hold SQUAREPrecision mode. While held, DPAD LEFT/RIGHT edits one display step at a time.
TRIANGLECopy current step, or reseed on the Generate page.
Release SQUAREPaste current step, or reset on the Generate page, unless it was being held for precision.
CROSS on a page tabToggle All Params / Only Autos where supported.
CROSS on a step cardToggle the step or FX-lane step.

Pages:

PageUse
SYNTHPer-step synth and sampler values.
FXPer-step insert FX values.
STEP FXRatchets, timing nudge, repeats, and conditional triggering.
GENERATEBuild and apply generated blocks from the selected step.

Automation notes:

  • LEVEL and VELOCITY are absolute per-step values.
  • Most other synth and FX automation is relative to the track's global Voice value.
  • Returning a relative automation value to zero removes that automation for the step.
  • Only Autos filters the current page to values that already have automation.
  • NUDGE shifts a step and its full ratchet group by clock ticks.
  • Generate applies from the selected step across the active pattern range.

Voice Editing

Voice edits the selected track's sound. The top row contains TYPE, ENG, and FX; the parameter grid edits synth, sampler, or FX values.

Top-row controls:

In edit mode, DPAD UP/DOWNPreview/change the pending value.
In edit mode, CROSSConfirm.
In edit mode, CIRCLECancel.
SQUAREOpen Presets from top controls on normal synth/sampler tracks.
CIRCLEBack toward the Voice section root.

Parameter controls:

ControlAction

Stick left/rightEdit the focused value.
Hold SQUAREPrecision edit with DPAD LEFT/RIGHT.
Release SQUAREToggle Synth/FX parameter pages when the track has insert FX.
TRIANGLEJump to the next parameter on the current page.

Some top controls require CROSS before changing so accidental D-pad movement does not rewrite the track type or engine.

Presets

Press SQUARE from Voice top controls to open Presets.

ViewControls
ActionsDPAD UP/DOWN chooses save/load/delete actions; CROSS opens; CIRCLE closes.
ListDPAD UP/DOWN chooses a preset; TRIANGLE previews; CROSS loads or deletes; CIRCLE backs out.
ConfirmCROSS confirms; CIRCLE cancels.
Name entrySame name-entry controls as Projects.

Loading a preset replaces the selected track's sound profile. Sampler presets include their PCM sample data.

SYN Note Picker

On compatible SYN controls, hold CROSS to open the SYN NOTE picker. Use DPAD to choose a note, L / R to change octave, CROSS release to set, and CIRCLE to cancel.

Sampler Workflow

Sampler tracks use the SP type and fixed sampler engine. The ENG top card selects ONESHOT or BEATSLICER. The REC parameter card opens recording or editing.

Recording

Focus REC and press CROSS.

ControlAction
DPAD UP/DOWNSelect the capture input.
DPAD LEFT/RIGHT or stickAdjust MIC gain when MIC is selected.
TRIANGLE on MICToggle input monitor.
TRIANGLE on RESAMPLECycle sync mode.
CROSSArm/start capture, disarm, or stop recording depending on state.
CIRCLECancel without replacing the current sample.
STARTPlay/stop unless the recorder is armed in a state where transport must not be interrupted.

Vita capture expects 48 kHz RAW input. If RAW input is unavailable, the record screen shows the relevant retry status instead of silently using lower-quality voice input.

Cropping

After recording or opening an assigned sample, DS-8 shows a crop editor.

ControlAction
DPAD UP/DOWNChoose IN or OUT.
DPAD LEFT/RIGHTFine-move the selected marker in the zoom view.
Stick left/rightMove the marker coarsely in the overview.
L / RSwitch pending sample type between one-shot and beat-slicer where available.
TRIANGLEPreview the cropped range.
CROSSTake the crop. One-shots assign immediately; beat-slicer advances to slicing.
SQUARERecord a replacement take.
CIRCLECancel without replacing the assigned sample.

Beat Slicing

Beat-slicer mode adds a slice stage after cropping.

AreaControls
Slice method controlsDPAD LEFT/RIGHT chooses MODE, VALUE, or APPLY; DPAD UP/DOWN changes MODE or VALUE; CROSS applies only on APPLY.
Waveform controlsDPAD UP/DOWN switches between the add cursor and slice cue cursor; DPAD LEFT/RIGHT fine-moves; stick left/right coarse-moves.
Global slice actionsL / R switches between method controls and waveform row; CROSS adds a cue from the add cursor; SQUARE deletes the focused cue; TRIANGLE previews the current slice; SELECT assigns; CIRCLE cancels.

Slice modes are MANUAL, GRID, and TRANSIENT. Grid values are 4, 8, 12, 16, 24, and 32; transient values are LOW, MID, and HIGH. Cue 1 is fixed at the beginning of the sample.

Playlist and Performance

Use the pattern/playlist switch in Transport to enter Playlist view. If the playlist has rows, focus enters the first actionable table cell. If it is empty, focus lands on the add-pattern transport control.

Playlist table controls:

FocusAction
Row launch cellCROSS launches or stops the row.
Pattern cellSQUARE opens the pattern picker. Hold SQUARE for momentary picker behavior.
Mute cellsCROSS toggles that lane mute for the row.
Cycle cellSQUARE opens the repeat-count picker.
Any rowSQUARE toggles row-move mode; then DPAD UP/DOWN reorders rows; SQUARE exits row-move mode.
Touch/tapTapping launch and mute cells uses the same action as focusing and pressing the button.

Playlist pickers:

PickerControls
Pattern pickerDPAD picks a pattern or row action, L / R changes pages, SQUARE or CROSS sets depending on the footer, CIRCLE cancels.
Cycle pickerDPAD picks repeat count or loop, release SQUARE to set, CIRCLE cancels.

Press L / R while Playlist view is active to cycle focus between Transport, the playlist table, and XY performance.

XY performance controls:

TRIANGLEHold for COMB.

The XY area is performance-only state; it is not saved as the persistent UI section.

Fast Workflows

Make a Basic Beat

  1. Enter Sequencer.
  2. Use DPAD to choose a track and step.
  3. Release CROSS to toggle steps on.
  4. Press START to listen.
  5. Press SQUARE for mute/solo options, or TRIANGLE on a step for automation.

Change a Sound

  1. Enter Voice.
  2. Use the top row to choose track TYPE, ENG, and FX.
  3. Move into the parameter grid.
  4. Use stick left/right to edit values.
  5. Hold SQUARE for precision edits.
  6. Release SQUARE to switch to FX params when available.

Save a Project

  1. Press SELECT.
  2. Choose LOAD/SAVE.
  3. Press CROSS.
  4. Choose SAVE or SAVE AS.
  5. Enter a name if prompted and press START.

Record a Sample

  1. Set a track to SP.
  2. Choose ONESHOT or BEATSLICER with the ENG card.
  3. Focus REC and press CROSS.
  4. Pick MIC, RESAMPLE, or imported audio where available.
  5. Record, crop, preview, then assign.
  6. For beat-slicer, set slice cues before pressing SELECT to assign.
