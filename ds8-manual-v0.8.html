DS-8 User Manual

This manual documents the main controls and workflows for using DS-8 on PS Vita. The UI is controlled by focus: move the focus to a section or control, then use the button shown in the footer to act on it.

New navigation in v0.8

Hold R to open the global navigator from almost anywhere. Use the D-pad to choose SEQUENCER, PLAYLIST, or DJ MODE, select its section, or open the TOOLBOX; release R to go there. For a faster move, keep holding R and tap a D-pad direction: left/right changes the top-level page, while up/down changes section. Tap SELECT for Settings and hold L+R in Sequencer Lanes for Pattern Navigator.

Version highlights

What's New in v0.8

v0.8 builds on v0.7 with a new performance workflow and major sound, sampler, and synchronization additions:

  • New navigation system: hold R for a global page/section navigator and Toolbox, or use R + D-pad shortcuts. A first-launch tutorial teaches the new controls.
  • DJ MODE: two direct-streaming decks with Track Prep, BPM analysis and caching, waveforms, hot cues, quantized launches, four assignable loops per deck, SYNC, pitch bend, filters, crossfader, DJFX, END loops, independent session recall, and sequencer-to-deck recording.
  • PCM POLY: a polyphonic sample-based engine with instrument categories, eight sounds per category, drum kits, shared chord shapes and voicings, envelopes, filters, LFO, and per-step automation.
  • 16-slot stereo LOOPER: each LOOPER track can hold 16 loops, select a different slot on every step, preserve stereo files, embed all occupied slots in projects and presets, and show per-slot sample size plus free RAM.
  • GRANULAR: a polyphonic granular sampler with position, spread, grain size, density, strum, chord/voicing controls, filter, drive, envelope, LFO, ties, and automation.
  • Performance sync: Ableton Link on PS Vita, improved MIDI clock/start-stop control, shared quantization for decks and sequencer, and seamless project changes while DJ decks keep playing.
  • Workflow refinements: redesigned Lane Actions with whole-track copy/paste protection, direct Step Automation step selection, STEP FX probability, melodic fine tune and empty-step preview, a shared audio browser, global/project themes, quick save, and clearer feedback throughout the interface.

Compatibility: projects from earlier releases still load. New PCM POLY, GRANULAR, multi-slot LOOPER, DJ-session, and navigation features require v0.8.

Core Ideas

DS-8 has three top-level pages: SEQUENCER, PLAYLIST, and DJ MODE. Each page shares Transport and aligns its main work area beneath it: Lanes and Sound in Sequencer, Arranger and XY FX in Playlist, or Decks and DJFX in DJ Mode.

Most screens follow the same rules:

Footer hints at the bottom of the screen are the best guide for the current focus. If a button seems inactive, move focus and check the footer.

Starting and Moving Around

The global navigator is the main way to move around v0.8. Hold R for half a second, use D-pad left/right to choose SEQUENCER, PLAYLIST, or DJ MODE, and use D-pad up/down to choose that page's section or the TOOLBOX. Release R to commit. Toolbox contains Settings, quick Save, Projects, and Help.

When a section frame is focused, press CROSS to enter its controls and CIRCLE to back out. Ordinary D-pad movement stays within the current section. Modal controls take priority over global shoulder actions, and one-shot navigation requires a fresh press rather than held repeat.

USB Audio and MIDI

In CONNECT TO COMPUTER mode, DS-8 can send multitrack audio and MIDI timing over USB and receive stereo USB audio for sampling. These device-mode features require the current psvita_usb_audio_midi.skprx kernel plugin supplied with the v0.8 download. Installing the DS-8 VPK alone does not install or activate the kernel plugin.

Before You Install

  • Back up ur0:tai/config.txt before changing it.
  • Disable VITAUVC00, VITASTICK, or any other plugin that takes over the Vita USB device connection.
  • Turn off VitaShell USB mode before using DS-8 USB features.
  • Incorrect taiHEN configuration or a plugin conflict can prevent normal startup. Hold L while booting to bypass plugins if you need to recover.

Install the USB Kernel Plugin

  1. Use the psvita_usb_audio_midi.skprx supplied with the v0.8 download. Replace an older DS-8 USB plugin rather than leaving both installed.
  2. Copy the extracted psvita_usb_audio_midi.skprx to ur0:tai/.
  3. Open ur0:tai/config.txt and find the existing *KERNEL section.
  4. Add ur0:tai/psvita_usb_audio_midi.skprx on its own line beneath *KERNEL. Do not create a second *KERNEL section.
  5. Save the configuration and reboot the Vita.
  6. Launch DS-8 and connect the Vita to the host with USB. The class-compliant device appears as PS Vita USB.

DS-8 already includes the app-side USB component. Only the .skprx kernel plugin needs to be installed manually.

USB Audio Channels

DirectionFormatUse
Vita to host10 channels at 48 kHz, 16-bitMaster L/R followed by Tracks 1-8 as discrete pre-FX channels for multitrack recording.
Host to VitaStereo at 48 kHz, 16-bitUSB audio input for the sampler recording, trimming, slicing, and assignment workflow.
USB MIDIClock and transportTiming Clock, Start, Continue, and Stop for external synchronization.

USB Host Mode for DJ Output

Choose CONNECT USB INTERFACE when the Vita should act as host for a class-compliant UAC1 mixer or sound card. A four-output interface receives MASTER on channels 1/2 and CUE on 3/4. With a stereo interface, MASTER goes to USB and the Vita headphone output becomes CUE. Handheld Vita models need OTG role wiring and external power; PSTV can use its host port. The current driver supports 48 kHz two- or four-channel UAC1 playback in signed 16- or 24-bit PCM. UAC2 is not supported.

If the kernel plugin is missing or incompatible, DS-8 continues to run but USB audio and USB MIDI are unavailable.

Remove or Recover the Plugin

  1. Remove the ur0:tai/psvita_usb_audio_midi.skprx line from ur0:tai/config.txt.
  2. Reboot the Vita, then delete the plugin file if you no longer need it.
  3. If a conflict prevents normal startup, hold L during boot, remove the line, and reboot again.

Performance and Credits

Ableton Link

PS Vita builds can synchronize tempo and beat phase over Ableton Link on a shared Wi-Fi network. Link Start/Stop Sync is optional: enable it when DS-8 should follow or publish transport state, or leave it off to share only tempo and phase. DJ decks, the sequencer, and quantized launches use the same performance clock. Incoming MIDI clock remains authoritative when MIDI sync is selected.

Dense projects can demand more from the PS Vita, especially when VOCODER uses 48 analysis bands. If audio glitches or drops out, lower the band count or simplify the project first.

Some users choose to run the Vita CPU at 500 MHz for additional headroom. This is optional and at your own risk; it can increase heat and battery use. Follow the official instructions for either PSVshell or PSVshellPlus. Their profile formats are not interchangeable.

CHORD uses wavetables from Adventure Kid Waveforms, released under CC0 1.0. ISOCORE is inspired by Isocore.

Pattern Navigator

Pattern Navigator shows all four 16-step pages and every lane as one continuous strip. The selected lane stays highlighted across the full pattern, while pages beyond the current length are dimmed.

  • Focus a disabled page and release L or R to extend to 32 or 64 steps.
  • When the disabled region is genuinely empty, press SQUARE to choose EXTEND: EMPTY or EXTEND: CLONE. Clone repeats page 1 into page 2, then pages 1-2 into pages 3-4.
  • To shorten a pattern, focus page 1 for 16 steps or page 2 for 32 steps and press TRIANGLE. Choose KEEP DATA to preserve hidden pages or ERASE DATA to clear them. The confirmation starts on CANCEL.

Automation notes:

  • LEVEL and VELOCITY are absolute per-step values.
  • Most other synth and FX automation is relative to the track's global Voice value.
  • Returning a relative automation value to zero removes that automation for the step.
  • Only Autos filters the current page to values that already have automation.
  • NUDGE shifts a step and its full ratchet group by clock ticks.
  • PROBABILITY sets a step's playback chance from 0% to 100% in 5% increments. One decision gates the complete ratchet group after the pattern-pass condition is checked.
  • RAMP PITCH glides to a -12..+12 semitone target. RAMP LEN sets a tempo-synced 1/16, 1/8, 1/4, or 1/2 duration. Automation-only steps can retarget an already-playing voice without triggering a new note.
  • Generate applies from the selected step across the active pattern range.

PCM POLY

Choose SP and PCM POLY for the new polyphonic sample-based engine. Track Snapshots

Choose SNAPSHOTS from Presets to store and recall eight sound states for the selected track. SQUARE stores the editable Voice, Mixer, swing, and insert-FX values in the focused slot. On compatible SYN controls, hold CROSS to open the SYN NOTE picker. Use DPAD to choose a note, L / R to change octave, CROSS release to set, and CIRCLE to cancel. Tapping a note selects and previews it without placing a trigger. On CHORD, committing also locks the selected chord shape on that step.

Effects

Track insert choices include BITCRUSH, DOWNSAMP, TONE, COMP, TREMOLO, COMB, PHASER, and FLANGER. Send 1 provides tape or BPM-synced delay, Send 2 provides CHVERB, and the master slot also offers DUCKER and FFOX. Press SQUARE from the parameter grid to switch between Voice and FX pages when an insert effect is active.

Sampler Workflow

Sampler tracks use the SP type. The ENG top card selects ONESHOT, BEATSLICER, LOOPER, MELODIC, or GRANULAR. The REC parameter card opens recording or editing.

LOOPER: 16 Slots Per Track

Each LOOPER track now holds 16 stereo-capable loop slots. The editor keeps SLOT 01..16 visible above both empty and occupied slots. Use L / R to focus another slot and immediately see its waveform or EMPTY state, sample size, and available RAM. Imports and recordings are assigned to the focused slot, and projects plus sampler presets embed every occupied slot.

Hold CROSS on a sequencer trigger to open the 4x4 SLOT TRIGGER grid. Choose and preview any occupied slot, or deliberately select a dimmed empty slot for a silent trigger. SLOT is also available in Step Automation, so every step and pattern can choose a different loop.

Every slot repeats in full and continuously repitches to follow the transport tempo from its original BPM. Stereo WAV/AIFF imports retain left and right channels; mono imports and recordings remain centered. The LOOPER filter offers LP12, BP12, HP12, and NOTCH with cutoff, resonance, and tempo-aware LFO. The crop editor lets you correct BPM and shows a duration-derived bar count.

Melodic and Granular Modes

MELODIC turns a sample into a monophonic playable voice with note, scale, root, cents-based fine tune, ADSR, and the same four-mode filter. Set LOOP START, LOOP END, and XFADE in the crop editor to build a smooth sustain loop. Recognizable pitches in filenames, such as C3, F#, or Ab2, initialize the sample pitch and playable note automatically. Holding CROSS on an empty melodic step previews the selected note without creating a trigger until release.

GRANULAR turns the full sample into a smooth polyphonic grain cloud. POSITION, SPREAD, SIZE, DENSITY, and STRUM shape the cloud; note, scale, root, chord, voicing, and added-note controls make it playable. Its Mixer adds ADSR, resonant low-pass filtering, drive, and an assignable free-running or tempo-synced LFO. Granular parameters, chord changes, and modulation can be automated, while ties extend a cloud without restarting matching grains.

Audio File Browser

Sampler import and DJ deck loading share one all-caps audio browser and remember the same current folder. Use D-pad up/down to move and wrap, D-pad left/right to jump to the first or last file, CROSS to open a folder or load audio, SQUARE to move to the parent folder, and CIRCLE to close. Hold TRIANGLE to preview a sampler file. In a deck browser, TRIANGLE ejects that deck while keeping the browser open; an unsaved deck recording asks whether to save or discard it first.

DJ Mode

Choose DJ in the Transport view switch, use R + D-pad left/right, or choose DJ MODE in the global navigator. DJ Mode combines two long-form audio decks with the DS-8 sequencer. WAV and AIFF tracks stream directly from storage instead of being copied into sampler RAM, so full songs and long recordings can be mixed.

END LOOPChoose a 1-, 2-, 4-, or 8-bar loop that starts automatically when playback reaches END.

START trims the playable beginning and defines the beat grid. END loops fall back from 8 to 4, 2, or 1 bar when the requested length will not fit. If later BPM or START changes make END invalid, its marker remains visible but disarmed until corrected.

Deck Performance Controls

Deck A and Deck B use stacked 16-beat moving waveforms with aligned center playheads. Each deck has SYNC, eject/load, play/stop, a momentary CUE gate from START, gain, a bipolar resonant filter, four assignable loop pads, and four hot cues.

ControlAction
SYNCMatch DS-8's performance tempo and align the next launch phase. Playback uses vinyl-style varispeed, so pitch follows tempo.
Play/stopLaunch or stop according to the global Q:OFF, Q:BEAT, or Q:BAR setting.
CUEPlay immediately from START while held, then stop and reset on release.
GAINAdjust from 50 to 200 in 10-point steps; 100 is unity. Hold SQUARE with D-pad left/right for precise steps.
FILTERSweep from resonant low-pass through neutral to resonant high-pass. Either stick edits a focused filter horizontally.
Right stick verticalApply temporary pitch bend for manual alignment.
XFADEBlend Deck A and Deck B with the equal-power crossfader. Hold SQUARE with D-pad left/right for precision.

Loops and Quantize

Each deck has four independently assignable loop pads. The two pads left of XFADE select 1/64, 1/32, 1/16, 1/8, or 1/4 bar; the two pads to the right select 1/2, 1/1, 2/1, 4/1, or 8/1. Duplicate assignments are allowed. Focus a pad and hold SQUARE with D-pad up/down to change its length without moving focus.

Pressing a loop pad enters at the closest beat. Press the active pad to queue exit, or press another length to keep LOOP IN and queue a replacement. Q:OFF applies immediately, Q:BEAT on the next beat, and Q:BAR on the next START-aligned bar. Pulsing loop markers show pending entry, replacement, or exit.

Output Routing and Sequencer Recording

Focus XFADE and press CROSS to open DJ OUTPUT ROUTING. Deck A, Deck B, and Sequencer can each follow the crossfader's LEFT or RIGHT side, bypass it with THRU, or use OFF. The separate pre-crossfader CUE bus can monitor any combination of all three sources. Use the USB host mode described above when MASTER and CUE need separate hardware outputs.

Double-tap an empty deck to open DECK A / RESAMPLE or DECK B / RESAMPLE. Choose 1, 2, 4, or 8 bars and arm capture to record the sequencer/master performance into a prepared deck loop. DS-8 loads and analyzes the result automatically. A newly captured deck is temporary until saved; ejecting, replacing it, or quitting asks whether to save or discard it, and interrupted recordings can be recovered on the next launch.

DJ Session, DJFX, and Clock

Use global navigation to move among DJ Transport, Decks, and the four-corner DJFX surface. DJFX processes the combined deck and sequencer mix. Deck files, cues, loops, gain, filters, SYNC, crossfader, quantize, BPM, routing, and DJFX are stored in the independent last DJ session and reopen prepared but stopped.

Loading or creating a song project resets only the sequencer layer. Live decks and DJFX continue without an audio gap, and the new sequencer waits for an explicit Play before joining the current phase. Ableton Link or incoming MIDI clock remains authoritative when enabled; otherwise the first audible local source establishes tempo and phase.

Fast Workflows

Make a Basic Beat

  1. Enter Sequencer.
  2. Use DPAD to choose a track and step.
  3. Release CROSS to toggle steps on.
  4. Press START to listen.
  5. Press SQUARE for mute/solo options, or TRIANGLE on a step for automation.

Change a Sound

  1. Enter Voice.
  2. Use the top row to choose track TYPE, ENG, and FX.
  3. Move into the parameter grid.
  4. Use stick left/right to edit values.
  5. Hold SQUARE for precision edits.
  6. Release SQUARE to switch to FX params when available.

Save a Project

  1. Hold R until global navigation opens.
  2. Move to the Toolbox and highlight SAVE.
  3. Release R.
  4. If the project is unnamed, enter a name and press START.

Record a Sample

  1. Set a track to SP.
  2. Choose ONESHOT, BEATSLICER, LOOPER, MELODIC, or GRANULAR with the ENG card.
  3. Focus REC and press CROSS.
  4. Pick MIC, RESAMPLE, or imported audio where available.
  5. Record, crop, preview, then assign.
  6. For beat-slicer, set slice cues; for granular, shape position, spread, size, density, and strum before assigning.
