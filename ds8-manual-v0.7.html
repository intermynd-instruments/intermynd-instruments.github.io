DS-8 User Manual

Looking for the Latest Manual?

You are viewing the archived v0.7 manual. For current controls, features, USB setup, and safety guidance, read the latest DS-8 Drumstream manual (v0.8).

This manual documents the main controls and workflows for using DS-8 on PS Vita. The UI is controlled by focus: move the focus to a section or control, then use the button shown in the footer to act on it.

Version highlights

What's New in v0.7

v0.7 turns DS-8 into a deeper sound-design and performance instrument:

  • Five expanded SYN engines: SH01, MONO, CHORD, redesigned ISOCORE, and VOCODER.
  • LOOPER and MELODIC sampler modes, sample normalization, and direct per-step BEATSLICER slice placement.
  • Eight snapshots per track, eight Scene Morphing pads, and scene launches from Playlist rows.
  • Pattern Navigator, sequencer undo/redo, and tempo-synced Step FX pitch ramps.
  • Expanded insert and master effects, including COMP, PHASER, FLANGER, and FFOX.

Existing USB users: DS-8 v0.7 requires the v0.2-compatible PS Vita USB Audio + MIDI plugin. Earlier plugin releases are for DS-8 v0.6.x.

Core Ideas

DS-8 has three normal work areas: Transport, Sequencer, and Voice. Playlist mode adds a playlist arranger and XY performance area.

Most screens follow the same rules:

ControlMain use
DPADMove focus, choose rows, or make coarse changes.
Left/right stickEdit the focused value continuously.
CROSSEnter, confirm, toggle, launch, or open the focused item.
CIRCLEBack, close, cancel, or open lane operations in the sequencer.
SQUARESecondary action: presets, mute/solo popup, precision hold, page swap, or picker set.
TRIANGLELocks/automation, preview, copy, reseed, or next parameter.
L / RSwitch major areas, or switch steps/pages/ranges inside modals.
STARTPlay/stop in most places. In name-entry screens it saves the entered name.
SELECTOpen Settings from normal screens. Some sampler edit screens use it to assign the pending sample.

Footer hints at the bottom of the screen are the best guide for the current focus. If a button seems inactive, move focus and check the footer.

Starting and Moving Around

Press START to play or stop the transport. Press SELECT to open Settings. Press L / R to move between top-level areas.

When a section frame is focused, press CROSS to enter that section's controls. Use CIRCLE to back out through the current hierarchy. In many lists and grids, moving past an edge returns focus to the parent section.

Hold a D-pad direction to repeat movement. DS-8 distinguishes a single press from a held repeat, especially in the sequencer and picker popups.

Transport

Transport contains play state, BPM, pattern navigation, the pattern menu, the pattern/playlist switch, and playlist-specific controls when Playlist view is active.

Common transport actions:

Shortening a pattern changes its playback endpoint without automatically erasing hidden pages. If you lengthen it again, preserved steps return. Pattern Navigator provides separate KEEP DATA and ERASE DATA choices when shortening.

USB Audio and MIDI

DS-8 v0.7 can send multitrack audio and MIDI timing over USB, and receive stereo USB audio for sampling. These USB features require the separately installed v0.2-compatible psvita_usb_audio_midi.skprx kernel plugin. Installing the DS-8 VPK alone does not install or activate the kernel plugin.

Before You Install

  • Back up ur0:tai/config.txt before changing it.
  • Disable VITAUVC00, VITASTICK, or any other plugin that takes over the Vita USB device connection.
  • Turn off VitaShell USB mode before using DS-8 USB features.
  • Incorrect taiHEN configuration or a plugin conflict can prevent normal startup. Hold L while booting to bypass plugins if you need to recover.

Install the USB Kernel Plugin

  1. Download and extract PS Vita USB Audio + MIDI v0.2. This is the compatible plugin release for DS-8 v0.7.x.
  2. Copy the extracted psvita_usb_audio_midi.skprx to ur0:tai/.
  3. Open ur0:tai/config.txt and find the existing *KERNEL section.
  4. Add ur0:tai/psvita_usb_audio_midi.skprx on its own line beneath *KERNEL. Do not create a second *KERNEL section.
  5. Save the configuration and reboot the Vita.
  6. Launch DS-8 and connect the Vita to the host with USB. The class-compliant device appears as PS Vita USB.

DS-8 already includes the app-side USB component. Only the .skprx kernel plugin needs to be installed manually.

USB Audio Channels

DirectionFormatUse
Vita to host10 channels at 48 kHz, 16-bitMaster L/R followed by Tracks 1-8 as discrete pre-FX channels for multitrack recording.
Host to VitaStereo at 48 kHz, 16-bitUSB audio input for the sampler recording, trimming, slicing, and assignment workflow.
USB MIDIClock and transportTiming Clock, Start, Continue, and Stop for external synchronization.

If the kernel plugin is missing or incompatible, DS-8 continues to run but USB audio and USB MIDI are unavailable.

Remove or Recover the Plugin

  1. Remove the ur0:tai/psvita_usb_audio_midi.skprx line from ur0:tai/config.txt.
  2. Reboot the Vita, then delete the plugin file if you no longer need it.
  3. If a conflict prevents normal startup, hold L during boot, remove the line, and reboot again.

Performance and Credits

Dense projects can demand more from the PS Vita, especially when VOCODER uses 48 analysis bands. If audio glitches or drops out, lower the band count or simplify the project first.

Some users choose to run the Vita CPU at 500 MHz for additional headroom. This is optional and at your own risk; it can increase heat and battery use. Follow the official instructions for either PSVshell or PSVshellPlus. Their profile formats are not interchangeable.

CHORD uses wavetables from Adventure Kid Waveforms, released under CC0 1.0. ISOCORE is inspired by Isocore.

Sequencer

The sequencer shows tracks as rows and steps as columns. Move around with the D-pad.

ControlAction
DPADMove selected track/step. Left/right can cross page boundaries.
CROSS releaseToggle the selected step.
TRIANGLEOpen Step Automation for the selected step.
SQUAREOpen the Track Action popup.
CIRCLEOpen Lane Actions when available.
Hold L + ROpen Pattern Navigator. Use DPAD LEFT/RIGHT to focus a page and DPAD UP/DOWN to focus a lane, then release either shoulder to open it.

Pattern Navigator

Pattern Navigator shows all four 16-step pages and every lane as one continuous strip. The selected lane stays highlighted across the full pattern, while pages beyond the current length are dimmed.

  • Focus a disabled page and release L or R to extend to 32 or 64 steps.
  • When the disabled region is genuinely empty, press SQUARE to choose EXTEND: EMPTY or EXTEND: CLONE. Clone repeats page 1 into page 2, then pages 1-2 into pages 3-4.
  • To shorten a pattern, focus page 1 for 16 steps or page 2 for 32 steps and press TRIANGLE. Choose KEEP DATA to preserve hidden pages or ERASE DATA to clear them. The confirmation starts on CANCEL.

Track Action Popup

Press SQUARE on an editable track in the sequencer to manage mute and solo states. The popup opens on the current active state when possible.

UNMUTE ALLClear all mutes.
UNSOLO ALLClear all solos.
MUTE QQueue a mute toggle for the next bar boundary.
SOLO QQueue a solo toggle for the next bar boundary.

Use DPAD to pick an action, release SQUARE to set it, or press CIRCLE to cancel. START still toggles playback.

Step Automation

Press TRIANGLE on a sequencer step to open Step Automation. The modal edits the selected step while keeping playback available.

Main controls:

ControlAction
CIRCLEClose the modal.
STARTPlay/stop.
L / RMove to previous/next step while keeping the modal open.
DPADMove through pages and parameter cards.
Stick left/rightEdit the focused value.
Hold SQUAREPrecision mode. While held, DPAD LEFT/RIGHT edits one display step at a time.
TRIANGLECopy current step, or reseed on the Generate page.
Release SQUAREPaste current step, or reset on the Generate page, unless it was being held for precision.

Pages:

PageUse
SYNTHPer-step synth and sampler values.
FXPer-step insert FX values.
STEP FXRatchets, timing nudge, tempo-synced pitch ramps, repeats, and conditional triggering.
GENERATEBuild and apply generated blocks from the selected step.

Automation notes:

  • LEVEL and VELOCITY are absolute per-step values.
  • Most other synth and FX automation is relative to the track's global Voice value.
  • Returning a relative automation value to zero removes that automation for the step.
  • Only Autos filters the current page to values that already have automation.
  • NUDGE shifts a step and its full ratchet group by clock ticks.
  • RAMP PITCH glides to a -12..+12 semitone target. RAMP LEN sets a tempo-synced 1/16, 1/8, 1/4, or 1/2 duration. Automation-only steps can retarget an already-playing voice without triggering a new note.
  • Generate applies from the selected step across the active pattern range.

Presets

Press SQUARE from Voice top controls to open Presets.

ViewControls
ActionsDPAD UP/DOWN chooses save/load/delete actions; CROSS opens; CIRCLE closes.

Loading a preset replaces the selected track's sound profile. Sampler presets include their sample audio. The sampler engine lists keep ONESHOT, BEATSLICER, LOOPER, and MELODIC separate.

Track Snapshots

Choose SNAPSHOTS from Presets to store and recall eight sound states for the selected track. SQUARE stores the editable Voice, Mixer, swing, and insert-FX values in the focused slot. CROSS recalls the snapshot using the selected morph duration; tapping a pad selects and recalls it directly. Overwriting an occupied slot requires confirmation and starts on CANCEL.

Scene Morphing

Choose SCENE MORPHING from Presets to open eight performance pads. Each scene refers to one existing snapshot for every participating track, so store the required track snapshots first.

ControlAction
DPADSelect one of eight scene pads.
CROSSLaunch the selected scene using its transition and launch settings.
SQUAREStore a scene from the most recently stored or recalled snapshot on each track.
TRIANGLEEdit track participation, snapshot references, duration, curve, launch quantization, discrete-switch point, and optional mute/solo capture.
Right stick left/rightScrub the active morph manually. Releasing resumes the synchronized transition from the current amount.
STARTStart or stop transport without leaving Scene Morphing.
CIRCLELeave the scene editor or close Scene Morphing.

Durations range from INSTANT to 16 BARS. Curves are LINEAR, SMOOTH, or STEPPED; launches can be immediate or quantized to the next beat, bar, or pattern end. Discrete controls and captured mute/solo state can switch at the start, midpoint, or end.

SYN Note Picker

On compatible SYN controls, hold CROSS to open the SYN NOTE picker. Use DPAD to choose a note, L / R to change octave, CROSS release to set, and CIRCLE to cancel. Tapping a note selects and previews it without placing a trigger. On CHORD, committing also locks the selected chord shape on that step.

SYN Engines

Choose SYN and then select an engine:

EngineCharacter and controls
ANALOGThe original flexible synth voice with wavetable and oscillator shaping.
SH01SH-101-inspired monophonic synthesis with saw, pulse, sub and noise levels, resonant filter, envelope, and free-running or tempo-synced LFO.
MONOCompact three-oscillator monophonic voice with curated oscillator sets, ladder filter, contour, mixer load, feedback, ADSR, and assignable LFO.
CHORDPolyphonic wavetable chord engine with 36 chord shapes, eight voicings, optional added note, filtering, and per-step chord selection.
ISOCOREFive experimental synthesis cores with two selectable waves, two modulation lanes, and core-specific sound controls and destinations.
VOCODERMultiband vocoder using an assigned sample, live microphone, or another track as its exclusive input, with chord carrier, tonal colors, 24/32/48 bands, formant shift, smear, edge, dry blend, envelope, and LFO.

For VOCODER, choose SAMPLE, MIC ON, or TRK01-TRK08 with INPUT. The source track stays audible; selecting the vocoder's own track is silenced to prevent feedback. INPUT GAIN adds up to 24 dB before analysis. Live microphone audio is heard only while vocoder notes are triggered.

Effects

Track insert choices include BITCRUSH, DOWNSAMP, TONE, COMP, TREMOLO, COMB, PHASER, and FLANGER. Send 1 provides tape or BPM-synced delay, Send 2 provides CHVERB, and the master slot also offers DUCKER and FFOX. Press SQUARE from the parameter grid to switch between Voice and FX pages when an insert effect is active.

Sampler Workflow

Sampler tracks use the SP type. The ENG top card selects ONESHOT, BEATSLICER, LOOPER, or MELODIC. The REC parameter card opens recording or editing.

Looper and Melodic Modes

LOOPER repeats the full sample and repitches it to follow the transport tempo from the loop's original BPM. Its filter offers LP12, BP12, HP12, and NOTCH modes with cutoff, resonance, and a tempo-aware LFO. The crop editor lets you correct the original BPM and shows the duration-derived bar count.

MELODIC turns a sample into a monophonic playable voice with note, scale, root, ADSR, and the same four-mode filter. Set LOOP START, LOOP END, and XFADE in the crop editor to build a smooth sustain loop. Recognizable pitches in filenames, such as C3, F#, or Ab2, initialize the sample pitch and playable note automatically.

Beat Slicing

Beat-slicer mode adds a slice stage after cropping.

AreaControls
Slice method controlsDPAD LEFT/RIGHT chooses MODE, VALUE, or APPLY; DPAD UP/DOWN changes MODE or VALUE; CROSS applies only on APPLY.
Waveform controlsDPAD UP/DOWN switches between the add cursor and slice cue cursor; DPAD LEFT/RIGHT fine-moves; stick left/right coarse-moves.
Global slice actionsL / R switches between method controls and waveform row; CROSS adds a cue from the add cursor; SQUARE deletes the focused cue; TRIANGLE previews the current slice; SELECT assigns; CIRCLE cancels.

Slice modes are MANUAL, GRID, and TRANSIENT. Grid values are 4, 8, 12, 16, 24, and 32; transient values are LOW, MID, and HIGH. Cue 1 is fixed at the beginning of the sample.

Direct BEATSLICER Slice Placement

To choose the exact slice played by a sequencer step, hold CROSS on that step. The SLICE TRIGGER picker opens as a 4x4 grid:

  • Use DPAD to select and preview a slice.
  • Use L / R to move through additional 16-slice ranges.
  • Release CROSS to assign the slice, or press CIRCLE to cancel.
  • Assignments appear as S01-style labels in the Sequencer and Pattern Navigator and participate in undo/redo.

Fast Workflows

Make a Basic Beat

  1. Enter Sequencer.
  2. Use DPAD to choose a track and step.
  3. Release CROSS to toggle steps on.
  4. Press START to listen.
  5. Press SQUARE for mute/solo options, or TRIANGLE on a step for automation.

Change a Sound

  1. Enter Voice.
  2. Use the top row to choose track TYPE, ENG, and FX.
  3. Move into the parameter grid.
  4. Use stick left/right to edit values.
  5. Hold SQUARE for precision edits.
  6. Release SQUARE to switch to FX params when available.

Save a Project

  1. Press SELECT.
  2. Choose LOAD/SAVE.
  3. Press CROSS.
  4. Choose SAVE or SAVE AS.
  5. Enter a name if prompted and press START.

Record a Sample

  1. Set a track to SP.
  2. Choose ONESHOT, BEATSLICER, LOOPER, or MELODIC with the ENG card.
  3. Focus REC and press CROSS.
  4. Pick MIC, RESAMPLE, or imported audio where available.
  5. Record, crop, preview, then assign.
  6. For beat-slicer, set slice cues before pressing SELECT to assign.
